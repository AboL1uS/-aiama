Основы ИИ

Что такое ИИ?

Искусственный интеллект (AI) — это область компьютерных наук, которая стремится создать программное обеспечение или машины, способные выполнять задачи, обычно требующие человеческого интеллекта.

                    // Пример псевдокода для мышления ИИ
                    Если (условие) {
                        Выполнить(действие);
                    }

Некоторые важные термины:

  • Машинное обучение
  • Нейронные сети
  • Обработка естественного языка
